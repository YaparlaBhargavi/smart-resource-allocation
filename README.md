# 🎯 Smart Resource Allocation System

An intelligent system that helps assign volunteers to emergency issues based on location, severity, and availability.

## ✨ Features

- **Smart Matching** – Automatically pairs volunteers with issues based on location and capacity
- **Priority Dashboard** – View high/medium/low priority issues at a glance
- **Real-time Analytics** – See volunteer utilization and issue distribution
- **CSV Support** – Upload your own data or use sample datasets
